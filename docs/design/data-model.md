# Données

Tables présentes : `channels`, `members`, `messages`, `events`, `access_grants` et `access_logs`. Les messages, événements, autorisations et journaux référencent les canaux et les membres. La table `clues` a été retirée : les étudiants doivent interpréter les archives sans catégorie préremplie qui distingue les indices des fausses pistes. Les messages de témoins portent des tags neutres communs, tandis que les événements correspondants réutilisent ces repères pour aider à vérifier la chronologie.
