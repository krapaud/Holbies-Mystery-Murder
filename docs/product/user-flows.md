# Parcours

1. Cloner le dépôt et lire le dossier de Jack Query.
2. Lancer `python3 main.py`, puis inspecter les tables dans la console d’enquête.
3. Résoudre les dossiers 1 à 6 par exploration, filtrage, tri et JOIN.
4. Recouper les éléments établissant le compte utilisé puis l'auteur de l'action.
5. Quitter avec `.exit` et saisir le flag dans le validateur.
6. En cas d'erreur, corriger et réessayer ; en cas de succès, contacter Kevin.
