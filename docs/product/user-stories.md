# User stories

- US-001 : l'équipe lance `python3 main.py`, puis explore les tables avec `.tables` et `.schema`.
- US-002 : l'équipe relie les tables et élimine les fausses pistes avec des JOIN.
- US-003 : les équipes croisent les archives avec au plus une jointure par requête, puis recoupent les éléments dans l'ordre compte utilisé puis auteur de l'action.
- US-004 : le validateur accepte le flag exact, refuse les autres sans révéler la solution et permet de réessayer.

Critères : aucune réponse n'est dans le README ou les fichiers étudiants ; un testeur externe peut suivre le parcours ; le message correct félicite l'équipe et indique de contacter Kevin.
