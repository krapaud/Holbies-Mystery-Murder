# Journal des décisions

## ADR-001 - SQLite local

SQLite est utilisé via la console d’enquête `python3 main.py`, sans service externe. La console laisse écrire du SQL standard, affiche les résultats et ajoute des relances de Jack Query.

## ADR-002 - Pas de Trello ni de solution enseignant

Le suivi est local et aucune solution n'est distribuée aux étudiants, conformément aux décisions de complétude.
